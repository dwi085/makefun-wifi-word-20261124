A [make.fun](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) bounty entry for **"One Word for Your Wi-Fi"**.

The program writes exactly one word to `/output/entry.txt` — the funniest,
truest description of home Wi-Fi, aiming to become the sponsor's network name.
The word is **ghosting**: home Wi-Fi ghosts you, there one second and gone
mid-sentence the next. Funny because it is true, and true because everyone
has lived it.

Run it with Node 22+:

```sh
node main.ts
```

It is deterministic (two runs produce byte-identical output), uses no network,
and honours `MAKEFUN_OUTPUT_DIR` when set (default `/output`).
